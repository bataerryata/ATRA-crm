# وضعیت پیاده‌سازی ATRA

## راهنمای وضعیت
- **تأییدشده/عملیاتی:** رفتار با کد، داده و تست واقعی اثبات شده است.
- **نیمه‌کاره:** بخشی از جریان کار واقعی است اما بخش‌هایی ناقص‌اند.
- **UI یا داده نمونه:** صفحه دیده می‌شود اما عملیات/داده واقعی اثبات نشده است.
- **بررسی‌نشده:** هنوز ممیزی نشده است.
- **مسدود:** به دسترسی، تصمیم یا سرویس بیرونی نیاز دارد.

## قواعد به‌روزرسانی
- وضعیت فقط بر اساس شواهد کد، اجرای واقعی یا تست تغییر کند.
- داده نمونه با داده عملیاتی اشتباه گرفته نشود.
- برای هر تکمیل، فایل‌ها، تست‌ها، نتیجه و ریسک‌های باقی‌مانده ثبت شوند.
- ادعای Build/Test موفق بدون اجرای واقعی ممنوع است.
